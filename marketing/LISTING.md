## Description

[IMG: strip.png]

**OZ is a pixel-art Tebex store theme for Minecraft servers.** It looks like your game, it sells like a modern store, and you set it up from the Tebex panel without touching code.

[IMG: cover.png]

### What you get

**Java & Bedrock login**
Players pick their edition, type their username and see their own skin before they buy. Bedrock names get your Geyser/Floodgate prefix added automatically.
*How:* choose **Login editions** and set **Bedrock username prefix** in the theme settings.

**Live 3D rank preview**
Rank pages show the player's real skin in 3D with the rank's nametag, and how they'll look in chat and the tab list. One click switches between ranks. A rank ladder shows what each step up costs.
*How:* set **Rank category**, then one line per rank in **Rank styles**: `VIP | [VIP] | #55FF55`.

**Rank comparison table**
One line per perk, one column per rank. `yes`/`no` become ✓ and ✕.
*How:* `Homes | 2 | 4 | 6` in **Rank comparison rows**.

**Quantity buttons**
Keys, coins and crates get ×1 ×5 ×10 ×15 buttons. The button shows the total price before the player adds it.
*How:* list the categories in **Quantity categories** and your amounts in **Quantity options**.

**Basket drawer**
The basket slides in from the side so players keep shopping. Add a free-gift goal to show a progress bar ("Spend 5 USD more for a free key").

**Ready-made pages**
Staff, Vote, FAQ, Patrons, Rules and News, with Minecraft skins and copy buttons. Create a Tebex page with that title and OZ styles it.
*How:* one line per entry, e.g. `Notch | Owner | Notch` for staff.

**Setup page**
A built-in checklist shows what's still missing, and editors write the settings text for you (staff, votes, FAQ, slider, rank table, icons, header links). Copy, paste into settings, done. Turn it off before launch.

**Sales tools**
- Homepage slider with images or YouTube videos
- Sale bar with a live countdown
- One-time discount pop-up with your coupon code
- Announcement bar
- Package badges: HOT, NEW, BEST VALUE
- Currency picker

**290 pixel icons**
Crowns, keys, coins, crates, pets, swords and more for categories and packages. Your own package images still work.

**Server info**
Copy-IP button with live player count, Discord button with member count.

**All 8 Tebex sidebar modules** restyled: server goal, community goal, top supporter, recent payments, featured package, server status, gift card balance and text box.

**Customer emails**
Abandoned cart, purchase follow-up and download emails styled to match.

### Requirements — please read

- **Tebex Plus** (needed for custom templates).
- A Tebex store that can use **custom Twig templates** (Webstore → Appearance → Templates). Stores that only use Tebex's new drag-and-drop **Storefront / Webstore Builder** can't run custom templates: Tebex has paused HTML/CSS editing there. If you're not sure, check that **Templates → Create Custom Template** is available in your panel before buying.
- Built for **Minecraft** (Java and/or Bedrock).

### Installing

A step-by-step guide is included (`docs/TEBEX-INSTALL.md`). In short:
1. Templates → Create Custom Template → base it on Exo.
2. Paste each page file into the matching page in the editor.
3. Upload the CSS, JS and Twig assets.
4. Paste `schema.json` into **Change Schema**.
5. Publish, activate, and fill in your server IP and Discord in settings.
