## 1. OZ Theme ($25)

**Title:** OZ - Pixel Minecraft Tebex Theme
**Summary:** Pixel-art Tebex store: Java & Bedrock login, quantity buttons, setup page, 9 presets
**Category:** Websites → Tebex → Tebex templates & themes
**File:** dist/OZ-Theme-v1.0.0.zip

### Description

[strip.png]

**OZ is a pixel-art Tebex store for Minecraft servers.** It looks like your game, sells like a modern store, and you set it up from the Tebex panel without touching code.

[s-product.png]
**Product & Basket.** Pixel package cards with badges, sale prices and an info pop-up. The basket slides in from the side so players keep shopping, with an optional free-gift progress bar.

[s-quantity.png]
**Quantity Selector.** Pick which categories get ×1 ×5 ×10 ×15 buttons (keys, coins, crates). The button shows the total before it goes in the basket.

[s-login.png]
**Java & Bedrock Login.** Players choose their edition and see their own skin before paying. Bedrock names get your Geyser/Floodgate prefix automatically.

[s-sidebar.png]
**Sidebar Modules.** All 8 Tebex sidebar modules restyled: server goal, community goal, top supporter, recent payments, featured package, server status, gift card balance and text box.

[s-setup.png]
**Setup Page.** A checklist shows what's still missing and editors write the settings text for you. Turn it off before launch.

[presets.png]
**Make it yours.** 9 presets (Frost, Overworld, Nether, End, Ocean, Cherry, Desert, Deep Dark, Jungle) or your own colours · category hotbar, tabs or sidebar · pixel scene, compact or minimal header · square, soft or round corners · light or dark mode · 290 pixel icons · copy-IP with live player count · Discord member count · announcement bar · package badges · homepage slider · styled customer emails · 138 settings, all in the Tebex panel.

**Optional add-ons ($5 each)**
- **Rank Preview:** live 3D skin with the rank nametag, chat and tab-list preview, rank ladder and comparison table.
- **Sales Pack:** sale bar with live countdown, one-time discount pop-up, currency picker.
- **Pages Pack:** styled Staff, Vote, FAQ, Patrons, Rules and News pages.

**Requirements, please read**
- Tebex Plus (needed for custom templates).
- A Tebex store that can use custom Twig templates (Templates → Create Custom Template). Stores that only use Tebex's new drag-and-drop Storefront / Webstore Builder can't run custom templates right now. Check your panel before buying.
- Minecraft Java and/or Bedrock.

**Install:** step-by-step guide included (docs/TEBEX-INSTALL.md). Message me if you'd like help installing.
