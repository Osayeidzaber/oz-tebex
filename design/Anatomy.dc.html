2 · Regions of every page (layout.html)

Announcement bar
Sale or event message, optional countdown
Server header
Logo · copy-IP + players online · Discord + members · login / user · basket count & total
Category navigation
All store.categories with sub-categories — sidebar or top bar
Content block
Page-specific: home, category, package, checkout, CMS page

Toasts from page.message sit on top
Modules
goal · community goal · top donor · recent payments · featured · server status · gift card · text
Basket drawer
Quick view of basket.packages without leaving the page
Footer
"Not affiliated with Mojang / Rockstar / Facepunch" · Terms · Refunds · Tebex note

3 · Pages & what each must answer

index.html
Where do I start? Categories, popular, current sale, store description
category.html
What can I get? Grid or list (displayType), price, sale, add / remove
package.html
Exactly what do I get? Media gallery, perks, one-time vs monthly, gift
username.html
Who receives it? ign field or external login (Steam, Discord, FiveM)
options.html
Pick server, variables, custom price
checkout.html
Hand-off to Tebex.js; terms
cms/page.html
FAQ, rules, supporters, terms — any custom page
Rank table
Tier comparison + upgrade price (cumulative packages)

4 · What players complain about → rule

Pay-to-win perks → label gameplay impact on every package
"Where's my rank?" → delivery time on package + basket
Upgrade confusion → show "you own X, pay only the difference"
Fake sales / badges → badges only from real discount data
Hidden currency / tax → currency always beside price, tax note in basket
